# ==========================================================
# Job Market Intelligence Platform - FastAPI backend
# backend/requirements.txt
#
# SCOPE: the REST API in backend/ (uvicorn -> backend.app.main:app).
#
# It imports three existing layers, so the shared dependencies are re-declared
# here to make the API self-contained in a container:
#
#   src/data/queries.py      -> psycopg, python-dotenv, pandas (variables from .env)
#   dashboard/components.py  -> streamlit, plotly (only pure functions are used)
#   ml/recommender.py        -> scikit-learn
#
# INSTALL (Windows PowerShell):
#   python -m venv .venv
#   .\.venv\Scripts\Activate.ps1
#   python -m pip install -r backend\requirements.txt
#
# RUN THE API:
#   python -m uvicorn backend.app.main:app --reload
# ==========================================================
